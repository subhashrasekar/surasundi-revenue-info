# महसूल मंडळ सुरसुंडी — माहिती पोर्टल (प्रारूप)

ही HTML/CSS/JavaScript वर आधारित responsive वेबसाइटची सुरुवातीची आवृत्ती आहे.

## फाईल्स
- `index.html` — वेबसाइटची पाने व मजकूर
- `style.css` — डिझाइन व मोबाईलसाठी responsive मांडणी
- `script.js` — मोबाईल मेन्यू, सूचना शोध आणि गाव शोध

## संगणकावर पाहण्याची पद्धत
1. ZIP फाईल Extract करा.
2. `index.html` वर double-click करा. वेबसाइट ब्राउझरमध्ये उघडेल.
3. मजकूर बदलण्यासाठी `index.html` Notepad किंवा VS Code मध्ये उघडा.
4. रंग/डिझाइन बदलण्यासाठी `style.css` संपादित करा.

## महत्त्वाचे
- अधिकारी-कर्मचारी नावे, गावांची यादी, कार्यालयीन वेळ आणि संपर्क क्रमांक हे placeholders आहेत. अधिकृत नोंदींवरून पडताळून भरा.
- सूचना व दस्तऐवज विभागातील नोंदी नमुना आहेत; सार्वजनिक करण्यापूर्वी त्या बदला किंवा काढून टाका.
- हे प्रारूप आपोआप अपडेट होणारे CMS किंवा सुरक्षित Admin Panel नाही. सूचना बदलण्यासाठी HTML संपादित करावी लागेल.
- अधिकृत वापरापूर्वी सक्षम प्राधिकाऱ्याची मान्यता, विभागीय संकेतस्थळ धोरण, माहितीची अचूकता आणि गोपनीयता नियम तपासा.
- सरकारी लोगो/राजचिन्ह वापरण्यापूर्वी संबंधित नियम व परवानगी तपासा.
- सार्वजनिक वेबसाइटवर आधार क्रमांक, वैयक्तिक मोबाईल क्रमांक, गोपनीय आदेश किंवा संवेदनशील जमीन अभिलेख प्रकाशित करू नका.

## मोफत ऑनलाइन प्रकाशित करण्यासाठी
ही static website GitHub Pages सारख्या static hosting सेवेद्वारे प्रकाशित करता येऊ शकते. त्यासाठी खाते, repository आणि publishing settings तयार करावे लागतात. सरकारी अधिकृत डोमेन समजू नये; सरकारी ओळख म्हणून सादर करण्यापूर्वी आवश्यक परवानगी घ्या.
